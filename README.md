**Image Locator Application**

This is a full-stack web application that allows users to upload images and see exactly where they were taken on a map. The app leverages Angular, TypeScript, Java, and the Google Maps API to provide an interactive and real-time geolocation experience.

Features:
- Upload images and display their location as markers on a Google Map.
- Extract EXIF metadata from images to determine precise geolocation.
- Interactive map features, including clickable markers and real-time location updates.
- Dynamic map rendering with accurate placement of photo locations.

Technologies Used:
- Frontend: Angular, TypeScript, HTML, CSS
- Backend: Java (Spring Boot)
- APIs: Google Maps API
